# Funngro Premium Two-Page Redesign

## Files
- `company.html` — For Companies / Brands
- `teen.html` — For Teens / Young Creators
- `styles.css` — Shared responsive premium styling
- `script.js` — Mobile navigation
- `robots.txt` and `sitemap.xml` — SEO starter files

## Run locally
Open either HTML file in a browser. No build tools or dependencies required.
Optional: run `python -m http.server 8000` and open `http://localhost:8000/company.html`.

## SEO included
Unique page titles and meta descriptions, canonical URLs, Open Graph and Twitter metadata, semantic HTML, JSON-LD WebPage schema, descriptive copy, internal links, FAQ content, robots.txt and sitemap.xml.

## Production checklist
1. Deploy `company.html` at `/for-brands` and `teen.html` at `/teen`, or update canonical URLs and sitemap to the actual routes.
2. Confirm metrics, campaign descriptions, age/eligibility terms, rewards and payout claims with Funngro.
3. Replace CSS-built dashboard illustration with approved image assets if available; add alt text and compressed responsive images.
4. Add `og:image` and `twitter:image` using an approved social preview asset.
5. Connect CTAs to approved enquiry and app store destinations.
6. Validate with Search Console, Lighthouse, PageSpeed Insights, Rich Results Test and accessibility checks.

Independent design concept only; it does not modify the live Funngro website.
